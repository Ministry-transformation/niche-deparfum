# NICHE DEPARFUM website concepts

Two responsive website concepts for NICHE DEPARFUM, published as a public, non-indexed concept review draft on GitHub Pages.

- `/` — black studio campaign and bespoke fragrance-selection concept.
- `/editorial.html` — the earlier warm editorial concept retained for client review.

The generated bottle images are conceptual art, not product photography. The catalogue, real assortment, service, prices, availability, delivery terms and legal information have not been verified. The preference form prepares example text in the browser only; it does not send or store submissions and does not place orders.

## Deployment

GitHub Actions publishes the repository root using GitHub Pages after pushes to `main`.
